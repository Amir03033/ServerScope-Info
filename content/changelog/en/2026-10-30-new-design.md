ServerScope has a completely new design and is now bilingual: English by
default, Dutch if you prefer.

### New

- A new design in the style of this website, in light and dark. By default
  it follows your system setting; switch with the toggle.
- **English by default, Dutch as an option.** E-mails, in-app notifications,
  Discord and webhooks use the language of the recipient.
- A new sidebar with groups: Monitoring, Incidents, Reporting,
  Administration and Account.
- Search with **⌘K / Ctrl+K**.
- Confirmation dialogs in the same style as the rest of the app.
- A rearranged dashboard: **Needs attention** comes first. Nothing set up
  yet? "Get started" guides you in three steps. Key figures only get a colour
  when they point at something.

### Fixed

- An alert rule could not be disabled.
- Creating a status page with the empty default row failed.
